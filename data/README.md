# Veri dosyası (yerel)

Orijinal büyük veri klasörünüzü **bu klasöre**, mevcut alt klasör adlarını değiştirmeden kopyalayın. Örneğin:

```
data/
  README.md
  AKCIGER_VERI_KLASORUM/
    Normal/...
    Benign/...
    Malignant/...
```

Bu sınıf adları sadece örnektir; kendi gerçek klasör isimlerinizi koruyun. Büyük veri otomatik olarak GitHub'a gönderilmez (bkz. `.gitignore`).

Dosyaları buraya taşıdıktan sonra `python scripts/veri_ozeti.py` çalıştırın. Betik dosya isimlerini paylaşmadan klasör bazlı görüntü sayılarını raporlar. Bu veri hasta/kişi bilgisi içeriyorsa kimliksizleştirme ve paylaşım izni gerekir. Kaynağın atıf/lisans şartlarını kontrol etmeden tüm görüntüleri yayınlamayın.
